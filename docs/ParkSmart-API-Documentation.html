1. Authentication APIs

POST
User Authentication
/api/auth/login
Public
Description

Authenticates standard user credentials and returns a signed JWT Bearer Token for protected routes.

Request Body (JSON)
FieldTypeDescription
emailStringRegistered email address (e.g. aakash@parksmart.com)
passwordStringAccount password (e.g. user123)
200 OK
Verified Response Sample
{
  "success": true,
  "message": "Login successful",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "role": "USER",
    "name": "Aakash Srivastava",
    "email": "aakash@parksmart.com"
  }
}

EasyOCR License Plate Recognition
http://localhost:5001/detect-plate
Public
Description
